# 👋 Bienvenido — Sitio web Mirande Aybar

Este es el sitio web profesional de tu inmobiliaria. Para verlo, hacé
**doble clic en `index.html`**.

## Qué incluye
- **Inicio** con animación 3D de las sierras y efectos al hacer scroll.
- **Propiedades** con filtros (casas, terrenos, departamentos, comerciales) y base de datos.
- **Equipo**: Sebastián Mirande y Mario Gonzalo Aybar.
- **Contacto**: formulario que envía la consulta a tu **WhatsApp** o **Gmail**.
- Botones de WhatsApp y email en todo el sitio + WhatsApp flotante.
- **Instagram y TikTok** en el pie de página.
- **Bilingüe Español / Inglés** (botón ES/EN arriba a la derecha).
- Optimizado para celular, tablet y computadora.

## Qué hacer ahora (en orden)

1. **Completá tus redes** → abrí `config.js` y pegá tus links de Instagram y TikTok.
   (WhatsApp, email y dirección ya están cargados.)

2. **Creá tu base de datos gratis de propiedades** → seguí **`GUIA-BASE-DE-DATOS.md`**.
   Mientras tanto, el sitio muestra propiedades de ejemplo.

3. **Publicá el sitio gratis en internet** → seguí **`COMO-PUBLICAR.md`**.

## Archivos importantes
| Archivo | Para qué sirve |
|---|---|
| `index.html` | La página. Doble clic para verla. |
| `config.js` | **Tus datos**: WhatsApp, email, redes, base de datos. Editable. |
| `GUIA-BASE-DE-DATOS.md` | Cómo crear tu base de datos gratis de propiedades. |
| `COMO-PUBLICAR.md` | Cómo poner el sitio online gratis. |
| `assets/` | Logos y fotos. |
